# 数据口径与字段字典

本文件说明 `beauty_review_weekly_20261108.html` 中全部图表的统计口径、数据字段与读图方式，便于复用或二次开发。
页面图表数据内嵌于 `beauty_review_weekly_20261108.html` 的 `const DATA = {...}`，同时导出为 [`data/report-data.json`](../data/report-data.json)，两者完全一致。

---

## 1. 统计口径

### 模块 1 · 初审大盘

| 项目 | 说明 |
| --- | --- |
| 范围 | 本土美妆 · **初审原生指标** |
| 复盘周期 | 2026-10-26 ~ 2026-11-08（W44 + W45，近双周 14 天）；环比对象为前双周 |
| 视频元素通过率 | 分子、分母**均为视频元素**，不是全量初审通过率的子集 |
| 双周通过率 | 按**日审核量加权**，不是 14 天的算术平均 |
| 数据源拆分 | 按账户 K 框近似拆分为「ADQ 侧常规 K 框」与「全域通」，**非严格投放端口径** |
| 月份完整性 | 11 月数据截至 11/08，为**不完整月**，逐月图中不可与整月直接比较 |
| 收益折算 |「少驳回条数」按放宽后阶段的月均审核量估算；阶段通过率按审核量加权 |

### 模块 2 · Top10 拒绝标签

| 项目 | 说明 |
| --- | --- |
| 范围 | 本土美妆 × 审核元素 = 视频，本周 W45 的**初审机审拒绝量** |
| Top10 取法 | 按本周拒绝量降序取前 10 |
| 剔除规则 | 已剔除**机审标签 / 黑词等客户不可控标签共 17 类**，详见报告末尾「已剔除标签」表 |
| 标签趋势 | 近 30 天按日；部分标签为期内新增，早期为断点（图中不连线） |
| 高命中名单 | 销售按客户级统一，仅保留**首位 RTX** |
| 案例帧 | 全部为**矢量示意帧**，非真实素材截图；规则解读与整改建议按标签语义与美妆合规经验整理 |

> 本公开版按需求**原样保留**了上述数据与客户 / 销售信息，未做匿名化或数值改写。对外发布前请确认披露授权。

## 2. 字段字典（`data/report-data.json`）

### `days14[]` — 近双周 14 天按日（14 条）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `day` | string | 日期，如 `"10.26"` |
| `all_total` | number | 当日初审总量（条） |
| `all_pass` | number | 当日初审通过率（%） |
| `video_total` | number | 当日视频元素总量（条） |
| `video_pass` | number | 当日视频元素通过率（%） |

### `months_video[]` — YTD 逐月（11 条，01 月 ~ 11 月）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `month` | string | 月份，如 `"01月"` |
| `video_total` | number | 当月视频元素总量（条） |
| `video_pass` | number | 当月视频元素通过率（%） |
| `adq_video_pass` | number | ADQ 侧视频元素通过率（%） |
| `qyt_video_pass` | number | 全域通视频元素通过率（%） |

### `rules[]` — Top10 标签（10 条，按拒绝量降序）

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `tag` | string | 标签名称 |
| `l1` / `l2` | string | 审核一级 / 二级标签 |
| `reject` | number | 本周机审拒绝量 |
| `daily_avg` | number | 本周日均拒绝量 |
| `trend` | array | 近 30 天按日：`[{ day, reject }]`；`null` 表示当日无数据 |
| `trend30_sum` | number | 近 30 天累计拒绝量 |
| `trend30_days` | number | 近 30 天有数据的天数 |
| `customers` | array | 高命中名单（客户简称、拒绝量、对应销售 RTX） |

## 3. 图表索引与读法

| 容器 ID | 类型 | 左轴 | 右轴 | 读法要点 |
| --- | --- | --- | --- | --- |
| `chart_ytd_video` | 柱 + 双折线 | 视频元素总量（万） | 两条通过率（%） | 竖线 ① 为 4 月下旬规则放宽、② 为 9 月下旬尺度放宽；通过率从 74.5% 抬升至 91.5% |
| `chart_days14` | 双柱 + 双折线 | 初审总量 / 视频元素总量（万） | 初审通过率 / 视频元素通过率（%） | 双周内量级波动与通过率走势对照 |
| `chart_top` | 水平条形 | 拒绝量（万） | — | 数值标签置于**条形右外侧**，Top3 用深色区分 |
| `chart_rule_0` ~ `chart_rule_9` | 迷你折线（10 张） | 单标签按日拒绝量 | — | 断点处不连线；用于判断标签是结构性高位还是短期突增 |

图表实现要点：

- 所有数值标签放在图形区域**外侧**，不压柱体 / 折线 / 其他文字
- 绝对量与通过率量级差异大，**分置左右双轴**，避免把百分比压平
- Top10 等长尾比较使用水平条形，标签有自然落点、不重叠
- 单图高度控制在 180 ~ 390px，整页保持横向 16:9 左右的阅读节奏
